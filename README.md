## 📌 About the Project

**Artha (अर्थ)** is an offline-first personal finance and wealth management application built with **Flutter**. It provides individuals with an intuitive, privacy-focused dashboard to track their cash flow, savings, debts, and appreciating assets.

### 🛡️ 100% Offline & Private
- All your financial data is stored **strictly on your local device / browser** (`IndexedDB` & local storage).
- **Zero cloud servers, zero trackers, and no login required.** Your financial numbers never leave your machine.

---

## ✨ Key Features

- **💵 Income & Expense Tracking:** Log daily transactions across custom categories with Indian numbering format (`₹1,25,000`).
- **🪙 Physical & Digital Gold Portfolio:** Track gold weight in grams/milligrams with automatic weighted average purchase price and SIP tracking.
- **📱 EMI & Loan Planner:** Schedule and monitor 3, 6, 12, or 24-month installments with one-tap payment toggles.
- **🎯 Savings Goals:** Create dedicated savings targets with visual completion progress bars.
- **📊 Monthly Budgets:** Set category spending limits with color-coded alerts (Green / Yellow / Red).
- **🔁 Recurring Transactions:** Automate monthly salaries, rent, and subscriptions with duplicate-prevention rules.
- **📈 Visual Analytics & Net Worth:** Instant income vs. outflow comparison charts and automated real-time Net Worth calculation:
  $$\text{Net Worth} = \text{Available Cash} + \text{Savings Goals} + \text{Gold Portfolio}$$
- **💾 JSON & CSV Portability:** Export full JSON backups, restore data anytime, and download transaction logs to CSV.
